# Подключение аккаунтов после независимых работ

На 22.10.2026 подключение отложено владельцем. Ниже реальные шаги, без фиктивных кодов, ID или подтверждений. Пароли от личных аккаунтов для этого не требуются: использовать вход владельца и делегированные права, когда сервис их поддерживает.

## Google Search Console

- Открыть https://search.google.com/search-console . Выбрать доменный ресурс `remontekt.ru` с DNS TXT либо URL-prefix `https://remontekt.ru/`.
- Взять выданный именно этим аккаунтом TXT, метатег или HTML-файл. Не создавать код самостоятельно. При TXT добавить отдельную запись, сохранив почтовые MX/SPF/DKIM/DMARC и остальные записи.
- При HTML разместить точный неизменённый файл в действующем document root, проверить HTTP 200 и содержимое по указанному Google адресу; при метатеге поместить точную выданную строку в head. Нельзя заменять проверку прав обычным текстом «verified».
- Нажать подтверждение. Сохранить выбранное доказательство во всех следующих релизах. Текущая публикация сохраняет найденные существующие proof-файлы; новая проверка требует настоящий файл/код.
- Передать https://remontekt.ru/sitemap.xml . Убедиться в успешном чтении карты. Проверить главную, `/uslugi/`, `/sovety/`, новостройки, капитальный и коммерческий ремонт через URL Inspection.
- Сверить canonical, индексирование, исключения, HTTP-ошибки, ручные меры и структурированные данные; проверить поле Core Web Vitals при наличии данных. Запросить индексирование важных новых страниц в доступном лимите; не рассылать все URL после каждой мелкой правки.
- Повторить Google Rich Results Test: публичная попытка 22.10.2026 вернула «Log in and try again». Не принимать это за ошибку разметки сайта или пройденный тест. Schema.org-проверка отдельно выполнена.

## Яндекс Вебмастер

- Открыть https://webmaster.yandex.ru/ , добавить `https://remontekt.ru/`, получить настоящий HTML-файл/метатег/DNS-запись и подтвердить право. Постоянно сохранять доказательство.
- Передать тот же sitemap. Проверить robots, обход и исключённые страницы, основной HTTPS-домен, canonical и диагностику.
- В региональности проверить Екатеринбург: фактический офис Тверитина, 44, офис 1006. Домашний юридический адрес ИП в Кыштыме не подменяет регион обслуживания.
- Переобход — для приоритетных новых/существенно изменённых страниц. Проверить ограничения сервиса. IndexNow не заменяет эту диагностику и не означает подключения кабинета.

## Wordstat / Keyword Planner / Trends

- Wordstat: регион Екатеринбург, фактическая дата выгрузки, запрос и использованные операторы. Сохранить широкую и уточнённую частотность раздельно. Не смешивать число показов со спросом в людях и заявках.
- Planner при наличии аккаунта: тот же регион/язык, реальные диапазоны и период; платную кампанию только ради формального заполнения таблицы не запускать. Trends — относительная динамика/сезонность, не абсолютная частотность.
- Совместить с собственными показами Search Console/Вебмастера; обновить `keyword-map.csv`, не заменяя неизвестные значения предположениями.
