# РЕМОНТ-ЕКТ: расширение SEO

Цель: получать обращения по ремонту квартир и новостроек в Екатеринбурге; коммерческий ремонт — отдельное направление. Пользователь передал реализацию и выбор приоритетов исполнителю.

Сохраняем основной дизайн, видимые тексты и фотографии главной, форму и архивные согласия. Изменения главной: поисковые метаданные и две ссылки на новые разделы в футере/мобильном меню.

Структура: /uslugi/ (хаб), 5 страниц услуг (капитальный, косметический, новостройки, вторичное жильё, коммерческие помещения), /sovety/ и 15 отдельных статей. Главная обслуживает общий запрос ремонта квартир в Екатеринбурге. Статьи группируются по планированию, инженерии и коммерческому ремонту. Каждый материал содержит самостоятельное содержание, навигацию, фотографии реальных объектов с честными подписями и ссылки по теме. Не выдумываем кейсы, сроки, цены, частотность, квалификацию авторов. Содержание помогает заказчику принять решения; инструкция выполнения опасных электромонтажных работ не входит в задачу.

Шаблоны: статический HTML, общая editorial.css и минимальный editorial.js. Они используют существующие локальные шрифты и палитру. Статьи и услуги доступны без JavaScript, навигация и заявки работают относительно подкаталога GitHub и в корне рабочего домена. Новые страницы используют существующую форму через ссылку на главную #request; без передачи введённых данных в URL.

Генератор: seo/content/*.json → HTML; один набор данных порождает карту запросов CSV, canonical/OG/JSON-LD, sitemap и ссылки. GitHub-макет noindex; рабочая сборка index для новых содержательных страниц. В sitemap только канонические индексируемые страницы, без юридических документов, черновиков, обработчиков, ключей и параметров. CSP сохраняется с хешами всех JSON-LD новых страниц.

Публикация: новый релиз на REG.RU, полный снимок предыдущего состояния, приватный каталог формы остаётся вне public root. Existing IndexNow verification files are retained. Проверяем публичные URL, HTML, ссылки, картинки, форму без отправки повторного тестового письма и новые страницы на 320/390/1440.

Ограничения доступа: Windsor не содержит подключённых Search Console/SEO-аккаунтов. Точные частоты Wordstat и статусы индексации не подменяем оценками. Оформляем пошаговое подключение владельцем и используем существующий IndexNow для уведомления новых страниц. Не приобретаем платные ссылки и не подключаем счётчики без отдельной задачи на данные/согласие.
