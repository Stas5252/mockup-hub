# 🌐 MOCKUP HUB — Каталог макетов сайтов в одном репозитории

Единая витрина для хранения десятков и сотен макетов сайтов без засорения профиля GitHub отдельными репозиториями. 

Каждый макет работает автономно и имеет **собственную прямую ссылку**, которую администратор может скопировать в один клик и отправить заказчику.

---

## 🚀 Как это устроено

```
/
├── index.html                   # Главная витрина (каталог с поиском, фильтрами и кнопками копирования)
├── viewer.html                  # Адаптивный просмотрщик макетов (десктоп, ноутбук, планшет, смартфон)
├── css/
│   └── style.css                # Черно-белый минималистичный дизайн с поддержкой тем
├── js/
│   ├── mockups-data.js          # База макетов (сюда в 4 строчки добавляется каждый новый сайт)
│   └── app.js                   # Поиск, фильтры, генерация ссылок и всплывающие уведомления
└── mockups/                     # Папка, где хранятся все ваши сайты
    ├── furniture-modern/        # Макет №1: Дизайнерская мебель
    ├── realty-luxury/           # Макет №2: Элитная недвижимость
    ├── auto-detailing/          # Макет №3: Авто-детейлинг
    ├── coffee-roastery/         # Макет №4: Крафтовая кофейня
    └── _template/               # Шаблон-болванка для быстрого создания нового сайта
```

## ⚡ Как загрузить на GitHub и включить бесплатный хостинг (GitHub Pages)

### Шаг 1. Инициализируйте Git и загрузите проект в GitHub
Выполните в терминале (в папке проекта):
```bash
git init
git add .
git commit -m "Первый релиз витрины макетов"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

### Шаг 2. Включите GitHub Pages
1. Перейдите в ваш репозиторий на GitHub.
2. Откройте вкладку **Settings** (Настройки) -> слева раздел **Pages**.
3. В графе **Build and deployment**:
   - Source: выберите **Deploy from a branch**
   - Branch: выберите ветку `main` и папку `/(root)`
   - Нажмите **Save**.
4. Через 1 минуту ваш сайт станет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## 🔗 Какие ссылки вы сможете отправлять клиентам

После включения GitHub Pages:

1. **Прямая ссылка на конкретный макет (клиент не видит каталог, а видит только свой сайт):**
   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/mockups/furniture-modern/
   ```
2. **Ссылка на интерактивный инспектор с переключением экранов (Десктоп/Планшет/Телефон):**
   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/viewer.html?site=furniture-modern
   ```
3. **Общая витрина всех макетов:**
   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
   ```

> 💡 **Кнопка «Копировать» в каталоге автоматически определяет текущий домен** (будь то GitHub Pages, локальный сервер или Vercel) и копирует идеальную готовую ссылку прямо в буфер обмена!

## ➕ Как добавить новый макет за 1 минуту

1. **Скопируйте папку** `mockups/_template/` и назовите её именем нового проекта (например: `mockups/barbershop/`).
2. Поместите туда файлы верстки (`index.html`, стили, картинки).
3. Откройте файл `js/mockups-data.js` и добавьте в массив `MOCKUPS_DATA` новый объект:
   ```javascript
   {
     id: "barbershop",
     title: "OldBoy — Мужская парикмахерская",
     category: "Услуги",
     folder: "barbershop",
     description: "Стильный брутальный лендинг барбершопа с онлайн-записью.",
     tags: ["Барбершоп", "Услуги", "Лендинг"],
     emoji: "💈"
   },
   ```
4. Сделайте `git add .`, `git commit -m "Добавлен макет барбершопа"`, `git push`.
5. Готово! Макет мгновенно появился в каталоге, отфильтрован по своей категории и имеет готовую ссылку.

## 🎨 Особенности интерфейса

- **Чистый черно-белый стиль**: Профессиональная типографика, отсутствие визуального шума.
- **Поддержка светлой и темной темы** (кнопка в правом верхнем углу).
- **Живой поиск**: Мгновенно фильтрует макеты по названию, тегам и описанию.
- **Интерактивный адаптивный фрейм**: Позволяет клиенту или вам прямо на главной странице протестировать, как сайт выглядит на iPhone или планшете.
