# Про Цветы

Адаптивный статический макет по предоставленному визуальному образцу. Добавлен в общий каталог и просмотрщик под идентификатором `pro-cvety`.

## Запуск и проверка

Из корня репозитория:

```sh
npm ci
node server.js
```

Открыть путь `/mockups/pro-cvety/` на запущенном сервере. Просмотрщик: `/viewer.html?site=pro-cvety`.

В другом терминале из корня репозитория:

```sh
node scripts/verify-pro-cvety.mjs
```

Проверка использует `/usr/bin/chromium`: четыре размера экрана, загрузка изображений, мобильное меню, выбор букета, валидация и демонстрационный результат формы, модальное окно, поиск в каталоге и просмотрщик. Сборка не требуется.

## Изображения

Сейчас используются временные изображения: сгенерированные фоновые композиции и фотографии из существующего макета BLOOM в этом репозитории. Прикреплённые пользователем фотографии и исходный фирменный знак ещё не перенесены: в текущем сеансе они доступны только как изображения в чате, без исходных файлов.

Для окончательной версии следует заменить:

| Файл | Назначение |
| --- | --- |
| `assets/hero.webp` | Основной букет первого экрана, горизонтальная фотография |
| `assets/work-1.webp` | Первая работа — нежные букеты |
| `assets/work-2.webp` | Вторая работа — авторские композиции |
| `assets/work-3.webp` | Третья работа — для особенного случая |
| `assets/about.webp` | Флорист за работой, горизонтальная фотография |
| `assets/flowers.png` | Декоративная композиция с прозрачным фоном |
| `assets/orchid.svg` | Временный рисованный знак орхидеи |

Для фотографий обновить также `alt` в `index.html` и описания слайдов в `app.js`. Логотип сейчас набран текстом со знаком орхидеи; исходный логотип потребует замены содержимого `.brand`.

Шрифты сохранены локально в `assets/fonts/`; лицензии Cormorant Garamond и Manrope находятся рядом. Страница не зависит от внешних CDN, библиотек и API.

## Форма и контакты

Это демонстрационный макет: форма проверяет обязательные поля, телефон и согласие, но не отправляет и не сохраняет персональные данные. Сообщение после отправки явно сообщает об этом. Выбор работы заполняет пожелания в форме. Перед подключением реального приёма заявок нужны обработчик, реквизиты оператора и окончательная политика обработки данных. Внешние социальные профили не выдуманы.
