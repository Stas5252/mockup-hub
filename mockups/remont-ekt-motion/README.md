# РЕМОНТ-ЕКТ — Motion

Автономная интерактивная версия сайта компании по ремонту в Екатеринбурге.

- Прямая ссылка: https://stas5252.github.io/mockup-hub/mockups/remont-ekt-motion/
- Просмотр в хабе: https://stas5252.github.io/mockup-hub/viewer.html?site=remont-ekt-motion

Сборка и серверные API не требуются. Все изображения, шрифты, GSAP, ScrollTrigger и Lenis находятся в этой папке; пути относительные. Форма формирует сообщение для WhatsApp.

Первый экран использует сгенерированную визуализацию одной квартиры до и после ремонта; она подписана «Визуализация ремонта». Фотографии портфолио, отзывы и контактные данные перенесены из исходного сайта компании. Предыдущий макет `mockups/remont-ekt` сохранён отдельно.
