# РЕМОНТ-ЕКТ — Motion

Автономная интерактивная версия сайта компании по ремонту в Екатеринбурге.

- Прямая ссылка: https://stas5252.github.io/mockup-hub/mockups/remont-ekt-motion/
- Просмотр в хабе: https://stas5252.github.io/mockup-hub/viewer.html?site=remont-ekt-motion

Для просмотра макета сборка и серверные API не требуются. Для автоматической отправки на рабочем домене нужен PHP 8.1+ и почтовый транспорт хостинга. Все изображения, шрифты, GSAP, ScrollTrigger и Lenis находятся в этой папке; пути относительные. На remontekt.ru форма отправляет заявку на dom196@list.ru; в макете готовит локальный текст.

Первый экран использует сгенерированную визуализацию одной квартиры до и после ремонта; она подписана «Визуализация ремонта». Фотографии портфолио, отзывы и контактные данные перенесены из исходного сайта компании. Предыдущий макет `mockups/remont-ekt` сохранён отдельно.

Файлы `hero-daylight.jpg`, `projmain-daylight.jpg`, `svc2-daylight.jpg` и `cta-daylight.jpg` — версии исходных фотографий с ИИ-коррекцией освещения. Они не являются новой съёмкой или новыми объектами. Оригиналы сохранены рядом; названия проектов и отзывы не изменены.

## Юридические документы и заявки — 14.10.2026

- `privacy.html`: политика обработки данных с реквизитами ИП Мягкова Е. И.
- `consent.html`: отдельное согласие; обязательный checkbox изначально не выбран.
- `cookies.html`: реальные технические данные и отсутствие счётчиков/cookies.
- `company.html`: исполнитель, юридический адрес и отдельно офис.
- Почта из предоставленной владельцем карточки: `dom196@list.ru`.
- Рабочая форма отправляет поля и отдельное согласие POST-запросом в request.php на своём домене; обработчик использует почту хостинга. Макет готовит сообщение локально. Данные не передаются в URL.
- Письмо включает номер, серверное время, редакцию и контрольную сумму согласия. Технические подтверждения размещены вне публичной папки. Повторы защищены от двойной отправки.
- Cookies, аналитика, localStorage/sessionStorage для заявок не подключены; баннер согласия на несуществующие трекеры не добавлен.
- Макет остаётся на GitHub Pages. Рабочий сайт размещён на REG.RU: https://remontekt.ru/.

Документы сайта не заменяют уведомления Роскомнадзора, проверку географии хранения почты/логов, внутренние документы, порядок удаления, права на контент и достоверность заявлений/цен. Эти вопросы должны быть подтверждены владельцем перед рабочим запуском.

Редакция согласия сохранена также в `consent-2026-10-14.html`. Для новой серверной отправки checkbox и письмо ссылаются на отдельную редакцию `consent-2026-10-14-mail.html`; прежний файл сохранён без изменений. При следующих редакциях сохраните старые версии и создайте новый датированный файл; не заменяйте содержание ранее выданного согласия.
