# Летучий корабль — редизайн

Интерактивный концепт сайта центра активного отдыха «Летучий корабль».

## Что внутри

- Cinematic hero с многослойным parallax и отдельным кораблём
- Выбор сценария «Куда полетим?»
- 4 полноэкранные scroll-storytelling сцены
- Программы с фильтрами и drag/swipe-каруселью
- Блок «С 2007 года»
- Публичные показатели Яндекс Карт без вымышленных отзывов
- Контактный CTA и форма с `mailto:` fallback
- Desktop и отдельная mobile-композиция
- GSAP + ScrollTrigger + Lenis при наличии сети
- Собственный vanilla fallback parallax без CDN
- `prefers-reduced-motion`

## Запуск

Самый простой вариант — открыть `index.html` в браузере.

Для корректной работы всех браузерных ограничений лучше запустить локальный сервер:

```bash
python -m http.server 8080
```

и открыть `http://localhost:8080`.

## Структура

- `index.html` — разметка
- `css/styles.css` — дизайн и адаптив
- `js/main.js` — интерактив и motion
- `assets/images/` — локальные финальные изображения

## Контент

Фактические направления и контакты основаны на публичной информации «Летучего корабля». Даты, цены и расписание программ специально не зафиксированы в макете: их лучше подключать к актуальному источнику перед публикацией.
