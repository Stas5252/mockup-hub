# TATIANA FURNITURE | Студия авторской мебели (Липецк)

Премиальный лендинг студии авторской мебели и кухонь по индивидуальным проектам (прямой производитель с 2014 года в Липецке).

## Демо сайта
🌐 **GitHub Pages**: [https://stas5252.github.io/tatiana-furniture/](https://stas5252.github.io/tatiana-furniture/)

## Особенности проекта
- **Архитектурная эстетика**: строгая геометрическая типографика на шрифте Manrope, глубокая темная палитра в стилистике Komandor.
- **Интерактивный конфигуратор (Квиз)**: 5-шаговый расчет бюджета с фиксацией бонусов и подарков.
- **Портфолио**: фильтрация реализованных проектов по категориям.
- **Материалы и технологии**: PUR-влагостойкость, ЧПУ Homag, оригинальная австрийская фурнитура Blum.
- **Адаптивность**: стабильная отзывчивая верстка на всех устройствах.
- **Автономность**: полностью самодостаточный бандл с встроенными оптимизированными ресурсами.
