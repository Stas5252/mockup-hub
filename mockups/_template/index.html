Новый макет сайта

Скопируйте эту папку mockups/_template в новую папку, например mockups/my-new-site

Как быстро добавить этот макет в витрину:

  1. Замените содержимое этого файла версткой вашего сайта (HTML, CSS, JS).
  2. Откройте файл js/mockups-data.js в корне проекта.
  3. Добавьте запись с названием вашей новой папки и нужной категорией: 
    {
  id: "my-new-site",
  title: "Название вашего сайта",
  category: "Мебель", // или Недвижимость, Авто, Услуги...
  folder: "my-new-site",
  description: "Краткое описание макета для карточки",
  tags: ["Лендинг", "Дизайн"],
  emoji: "✨"
}
  4. Сохраните файл. Макет моментально появится в каталоге с готовой ссылкой!
